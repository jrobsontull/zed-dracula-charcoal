# Dracula Charcoal for Zed

Dracula syntax colors on a neutral charcoal (`#202020`) background, with
`#f8f8f2` text, a `#353535` active line and a `#44475a` selection. It matches
the "Dark-Dracula" theme for VS Code, and the panels are opaque.

## Installation

Copy `themes/dracula-charcoal.json` to `~/.config/zed/themes/`, then pick
"Dracula Charcoal" from `theme selector: toggle`. Or set it in `settings.json`:

```json
"theme": { "mode": "dark", "light": "One Light", "dark": "Dracula Charcoal" }
```
